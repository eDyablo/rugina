# Rugina

Hands-on Rust examples exploring core language concepts and practical Rust code snippets for understanding fundamentals.

## Componets

[Repolet](./repolet/) - A small library showcasing a generic repository abstraction with standard operations

[Repoletio](./repoletio/) - A library demonstrating how to expose repolet repositories via an async, modular server framework in Rust

[Repoplay](./repoplay/) - A small application demonstrating async repository operations and server interactions using repolet and repoletio
